# Icons folder

Sebelum production, replace file placeholder di sini dengan icon asli:
- `icon-192.png` (192×192 px)
- `icon-512.png` (512×512 px)  
- `icon-maskable-512.png` (512×512 px, safe zone 80%)

Cara generate cepat:
1. Buka https://www.pwabuilder.com/imageGenerator
2. Upload logo brand (minimal 512×512)
3. Download bundle, ekstrak file yang diperlukan ke folder ini

Sementara belum ada file PNG, install prompt PWA tetap muncul tapi 
menampilkan icon default browser.
